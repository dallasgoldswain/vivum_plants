## Searching

Type a word or two in the search box, such as "invite" or "backup codes". Guides
show only for features you can use.

## Help from any page

Look for **Help** beside a page's heading. It opens the guide for that page.

## What's new

**What's new** lists recent changes to VIVUM Plants. A dot next to it means
there's something you haven't seen yet.
